# varunvaid.com

Vaid City: a neon cyberpunk megacity you fly a hover-gunship through, in the browser.

Everything is in `index.html` (Three.js from a CDN, no build step). GitHub Pages serves it from `main`; `CNAME` points it at varunvaid.com.

## Controls

Mouse steers, W accelerate, S brake, Shift boost, Space drift, E use, R reset, M sound. On phones: left stick plus on-screen buttons.
